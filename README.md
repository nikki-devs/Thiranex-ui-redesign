# Website UI Redesign

A UX/UI redesign of [Website Name] ([URL]), created in Figma. The project covers
the full design process: auditing the existing site, defining a visual language,
and delivering high-fidelity, responsive mockups.

## Project Overview

[Website Name] was chosen because [one-sentence reason]. The current site has
usability, navigation, visual hierarchy and accessibility issues that make key
tasks such as [main task] harder than they should be. This redesign addresses
those issues with a consistent, accessible and modern interface.

## What's Included

1. **Heuristic Evaluation**: Review of the existing site against Nielsen's 10
   usability heuristics and accessibility checks, with severity ratings and
   proposed fixes.
2. **Mood Board and Style Guide**: Color palette, typography scale, spacing
   system, and UI components (buttons, inputs, cards, icons, navigation).
3. **High-Fidelity Mockups**: Redesigned key screens: [Home, Listing, Detail,
   Login, Contact].
4. **Responsive Layouts**: Desktop (1440px), tablet (768px) and mobile (390px)
   designs built on a 12/8/4-column grid.
5. **Prototype** (optional): Clickable flow for [main user task].

## Design Goals

- Resolve all high-severity usability issues found in the audit
- Meet WCAG 2.1 AA color contrast
- Keep the main task within 3 clicks of the home page
- Use one consistent design system across all screens and breakpoints
